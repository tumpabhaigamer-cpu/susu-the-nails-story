# SuSu The Nails Story — website concept

A premium website concept for SuSu The Nails Story, Far East Plaza, Singapore.

- Instagram: https://www.instagram.com/susuthenailsstory/
- Visual direction: editorial plum, soft ivory, rose accents, expressive nail-art lookbook.
- Portfolio images are from the public Instagram profile and are bundled locally in the repository root for this concept.
- Booking CTA opens a prefilled WhatsApp message for the visitor to review and send.

Open `index.html` in a browser to preview. No build step required.
